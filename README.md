## Mise en ligne
1. Crée un nouveau repo GitHub, ex. `Quest-ce-qu-un-retcon`
2. Pousse ces fichiers à la racine
3. Active GitHub Pages (Settings → Pages → branche `main`, dossier `/root`)
4. L'article sera accessible à `https://djewhom.github.io/Quest-ce-qu-un-retcon/`
5. Ajoute un lien vers cet article depuis la page d'accueil de `Dragonballologie` si tu en as une.
